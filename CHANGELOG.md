# Changelog

## [1.0.0] — 2026-06-07

### Added
- Initial release: bead art pattern designer
- 29x29 grid with 16-color palette
- Place, erase, and flood fill tools
- Undo/redo support
- Bead count statistics
- BeadEngine for stats computation and grid validation
- IDesignRepository with in-memory implementation
- 4 test classes covering engine, grid, palette, and repository (25+ test cases)
- Gradle version catalog
- CI/CD pipeline (GitHub Actions)
- ProGuard rules for release builds
